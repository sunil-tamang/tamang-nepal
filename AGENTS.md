# TAMANG Nepal — Codex Agent Instructions

## Role
Act as a senior creative director, UI designer, and Jekyll frontend developer.

## Visual Direction
- Premium independent design brand.
- Contemporary editorial layout.
- Soft sage, warm off-white, deep green, charcoal.
- Strong typography, generous whitespace.
- Authentic photographs and real products.
- Follow approved design references.
- Avoid generic templates and artificial imagery.

## File Scope
- Inspect only files relevant to the current task.
- Prefer targeted searches over full repository scans.
- Homepage work: inspect homepage source, relevant layouts, shared styles, and required assets.
- Avoid scanning unrelated directories, dependencies, caches, and generated output.
- Reuse previous findings rather than rereading files unnecessarily.

## Development
- Maintain existing Jekyll/Liquid architecture.
- Reuse components and collections.
- Keep JavaScript minimal.
- Build responsive and accessible pages.
- Preserve existing URLs, content, SEO, and image assets.
- Do not introduce unnecessary frameworks.

## Content
- Never invent products, prices, makers, statistics, or sustainability claims.
- Use existing product photography whenever possible.
- Mark missing images and information clearly.

## Workflow
1. Inspect relevant files.
2. Explain proposed changes.
3. Request approval for major redesigns.
4. Implement one page at a time.
5. Verify functionality and Jekyll build.
6. Summarize changed files.

## Restrictions
- Never delete content without approval.
- Never overwrite original photographs.
- Never modify deployment, DNS, or GitHub Actions without approval.
- Never commit, push, or deploy without approval.
- Never create fake buttons or unsupported features.
